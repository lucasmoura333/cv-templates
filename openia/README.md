# Coleção OpenIA

Cinco templates de currículo com CSS externo, focados em ATS, legibilidade e impressão A4. Normalizados para o padrão global desta pasta: cada template é uma pasta com `index.html`, `styles.css`, `index.json` e, quando havia, `preview.pdf`.

## Templates

| # | Template | Layout | ATS | Destaque |
|---|---|---|---|---|
| 01 | [ATS Corporate](template-01-ats-corporate/) | 1 coluna | excelente | conservador, triagem automática |
| 02 | [Modern Editorial](template-02-modern-editorial/) | sidebar | bom | blocos de projeto com tags |
| 03 | [Technical Dense](template-03-technical-dense/) | 1 coluna densa | muito bom | grid de especialidades |
| 04 | [Executive Premium](template-04-executive-premium/) | 1 coluna | bom | serifado, números de impacto |
| 05 | [Creative Tech](template-05-creative-tech/) | 2 colunas | médio | marca gráfica + cards |

Galeria: [`index.html`](index.html).

## Observações

- Os CSS originais usavam `style.css`; foram renomeados para `styles.css` (padrão global) e o `<link>` atualizado.
- Os PDFs originais viraram `preview.pdf` dentro de cada template.
